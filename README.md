 Cinema Seat Booking System

 Description
A Java application that manages cinema seat bookings using HashMap and HashSet.

 Features
- Book cinema seats.
- Check whether a seat is available.
- Retrieve customer names.
- Prevent booking an already reserved seat.
- Prevent booking broken seats.
- Move bookings between seats.
- Display the seating chart.

 Concepts Used
- HashMap
- HashSet
- equals() and hashCode()
- Java Records

 How to Run

Compile:
```bash
javac Task_CinemaBooking.java
```

Run:
```bash
java Task_CinemaBooking
```
